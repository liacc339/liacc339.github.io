NOTE / AI ARCHITECTURE

Agent 和 Workflow，什么时候该选哪一个？

我越来越觉得，架构选型并不是新名词的比赛。场景的确定性和容错要求，比“智能程度”更值得优先讨论。

AI 应用架构WorkflowAgent

先看任务本身

如果任务步骤清楚、规则稳定、需要可审计，优先考虑 Workflow；如果任务目标相对明确但路径不固定，需要自主选择工具或探索步骤，可以考虑 Agent。

从排课说起

教室容量、老师时段、课程冲突属于硬约束，应该由规则或确定性逻辑检查；课程介绍润色、用户意图理解则更适合由模型承担。把两类责任分开，反而更可靠。

一个实践原则

先做最小闭环，优先保证可观察、可复现、能评估，再逐步增加自主性。
