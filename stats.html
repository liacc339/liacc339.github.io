一次性连接 Cloudflare，之后直接从本站查看

Cloudflare 已经在网站收集浏览数据，但 GitHub Pages 无法直接读取私人统计接口。为避免公开 API 密钥，需要先开启一次自动汇总。

  1. 在 Cloudflare API Tokens 创建仅有 Account → Account Analytics → Read 权限的令牌。
  2. 在 GitHub 仓库 → Actions secrets 添加两个 Repository secrets：CF_ACCOUNT_ID（Cloudflare 账户 ID）和 CF_API_TOKEN（刚才生成的令牌）。
  3. 打开 网站统计自动更新，点击 Run workflow 首次运行。此后每天自动同步。

不要把 API 令牌发到聊天、写进网页代码，或上传到公开仓库。

访问量为浏览器统计，可能受广告拦截与 Cloudflare 抽样影响；PV 不等于独立访客数。本站公开展示的汇总数据不包含个人信息。平均阅读时长尚未采集，不能用加载时间冒充。
